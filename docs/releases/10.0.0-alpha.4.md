# Entity Controller 10.0.0-alpha.4

Date: 2026-09-30

Fourth v10 architecture milestone. This prerelease adds the first native controller entities and compatibility actions on top of the alpha.3 runtime/manager lifecycle.

Changes:
- native controller device metadata scoped by root config entry and controller subentry;
- state sensor exposing exact FSM states and runtime attributes;
- Enabled switch that stops EC decision-making without turning loads off;
- Stay Mode switch for runtime stay behavior;
- Blocked binary sensor with reason/source attributes;
- Activate button;
- compatibility runtime actions for activate, clear block, enable block, stay mode, and current no-op night-mode placeholder;
- service metadata updated to current stay-mode service names.

Limitations:
- Config Flow/Subentry UI is not implemented yet;
- no v9 YAML migration yet;
- not intended for production migration.
