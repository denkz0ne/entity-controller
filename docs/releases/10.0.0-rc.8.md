# Entity Controller 10.0.0-rc.8

## Changes

- Show each controller as its own Home Assistant device config entry.
- Add controllers directly from the integration page and edit them from their own settings.
- Migrate v10 prerelease controllers while retaining device and entity registry identity.

- Include a universal custom integration icon in the HACS package.
