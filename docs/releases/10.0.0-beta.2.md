# Entity Controller 10.0.0-beta.2

Date: 2026-09-30

Second v10 beta milestone. This prerelease modernizes repository metadata, CI, and user documentation for the v10 development line.

Changes:
- HACS metadata now advertises Home Assistant `2026.9.0` as the v10 floor;
- legacy Node 12 release automation was removed;
- GitHub Actions now installs current test dependencies, runs Ruff over the maintained v10 surface, validates repository metadata, and runs the v10 pytest suite;
- README now points to v10 configuration, actions, behavior, migration, troubleshooting, and development docs;
- new action and behavior docs describe native controls, compatibility actions, FSM states, helper composition, and migration boundaries.

Limitations:
- HACS validation is represented by repository metadata tests in this branch; full HACS marketplace validation remains part of the release-candidate gate;
- old v9 test files remain in the repository for reference but are not part of the maintained v10 CI surface.
