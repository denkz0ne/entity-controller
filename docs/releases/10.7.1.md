# Svetlo v tme 10.7.1

This release groups trigger mode and adaptive timer settings with the
controlled entities and timeout in **Čo a ako dlho ovládať**, in both editor
modes. Duration-only reset and adaptive backoff fields appear only when
relevant, while their saved values remain intact.

It also includes fixes for compressed Home Assistant Recorder history in the
24-hour sidebar timeline and for preserving active controller sessions across
Home Assistant restarts without false manual-takeover detection.

## Upgrade

Update the existing HACS repository entry to 10.7.1. No configuration
migration is required.
