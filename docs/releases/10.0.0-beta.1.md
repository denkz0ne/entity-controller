# Entity Controller 10.0.0-beta.1

Date: 2026-09-30

First v10 beta milestone. This prerelease adds controller-owned persistence helpers, diagnostics, and migration Repair issue builders on top of the alpha.6 migration importer.

Changes:
- capture and restore Entity Controller-owned Enabled and Stay Mode state;
- restore valid active timer expiry without replaying transition side effects;
- keep external Helper state outside Entity Controller persistence;
- expose stable, redacted diagnostics for config entry data, controller state, timer metadata, and controller-scoped errors;
- add guide-only migration Repair issues for legacy YAML cleanup and warning review;
- keep migration Repairs idempotent and non-fixable so EC never deletes Helpers or YAML;
- add a public single-controller reconcile hook for unavailable entity recovery.

Limitations:
- startup wiring for automatic migration/Repair issue creation is still pending;
- real Home Assistant 2026.9 validation remains required before release candidate;
- diagnostics cover the v10 runtime surface currently implemented on this branch.
