# Entity Controller

Entity Controller v10 is a Home Assistant helper integration for reusable finite-state-machine controllers. It targets Home Assistant 2026.9+ and uses Config Entries, controller subentries, native entities, diagnostics, and a controlled migration path from legacy YAML.

## Status

The v10 line is currently a release candidate. Back up Home Assistant before testing migration from an older YAML configuration.
