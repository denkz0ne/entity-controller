# Entity Controller 10.0.0-rc.7

Date: 2026-10-01

This release candidate restores low-churn runtime diagnostics on the native controller entities and in the config-entry diagnostics download.

Changes:
- retain the source entity for real FSM transitions;
- expose transition cause/time separately from reconcile reason;
- expose active trigger, override, interlock, and state entities;
- explain blocking on the State and Blocked entities, including source and timeout;
- add runtime/config summaries to diagnostics while preserving recursive secret redaction;
- keep existing `last_transition`, `transition_cause`, and blocked `reason` attributes as compatibility aliases;
- no per-second countdown attributes or reconcile-generated fake transitions.

Interlock timeout and FSM semantics remain tracked separately in Issue #5.
