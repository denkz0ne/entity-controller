# Entity Controller 10.0.0-alpha.2

Date: 2026-09-30

Second v10 architecture milestone. This prerelease replaces the legacy `transitions`-based state machine core with an explicit async runtime and introduces structured schedules, Home Assistant Context tracking, and cancellable async timers/backoff semantics.

Changes:
- explicit typed FSM with `idle`, `active_timer`, `active_stay_on`, `blocked`, `overridden`, `constrained`, and `disabled` states;
- v9-compatible event/duration trigger behavior, override exit rules, stay mode, and manual-control blocking;
- side-effect-free reconcile path for startup/restore/reconfigure work;
- structured fixed/sunrise/sunset schedule points with cross-midnight window evaluation;
- legacy schedule-string conversion for migration use;
- bounded Home Assistant Context tracker using native `Context` parent relationships;
- cancellable async timer abstraction with stale-callback protection;
- backoff factor/max calculation and duration-sensor pending-expiry behavior.

Limitations:
- manager/entity listeners are not wired to live HA states yet;
- no Config Flow/Subentry UI yet;
- no v9 YAML migration yet;
- not intended for production migration.
