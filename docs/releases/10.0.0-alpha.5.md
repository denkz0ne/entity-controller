# Entity Controller 10.0.0-alpha.5

Date: 2026-09-30

Fifth v10 architecture milestone. This prerelease adds the first native Config Entry/Subentry configuration surface and EN/SK translation files.

Changes:
- manifest enables `config_flow`;
- root Entity Controller config flow;
- controller subentry flow handler;
- basic controller add/reconfigure normalization;
- reconfigure result is modeled as subentry update without root reload;
- external override/interlock Helper references are preserved as ordinary entity references;
- `strings.json`, English translation, and Slovak translation include `config_subentries.controller`.

Limitations:
- full Home Assistant 2026.9+ selector behavior still needs validation against the target HA dev environment;
- no v9 YAML migration yet;
- not intended for production migration.
