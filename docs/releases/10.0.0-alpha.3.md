# Entity Controller 10.0.0-alpha.3

Date: 2026-09-30

Third v10 architecture milestone. This prerelease wires the v10 runtime into a manager-owned controller lifecycle and adds hot per-controller reconfiguration without rebuilding the root integration entry.

Changes:
- manager APIs for adding, updating, and removing controller runtimes;
- startup reconcile from current Home Assistant state without transition enter/exit side effects;
- live state listeners for trigger, control/state, override, and interlock inputs;
- isolated reconcile errors so one unavailable/broken configured entity disables only its controller;
- listener cleanup when a controller is removed or reconfigured;
- hot config application that preserves runtime identity;
- active timer rescheduling from the original trigger timestamp when delay changes;
- stale timer callback rejection after reconfigure;
- immediate reconcile when newly selected external helpers are already active.

Limitations:
- native controller entities and service/action replacement are not implemented yet;
- no Config Flow/Subentry UI yet;
- no v9 YAML migration yet;
- not intended for production migration.
