# Entity Controller 10.0.0-rc.1

Date: 2026-09-30

First v10 release candidate. This build freezes the current v10 migration/smoke expectations and publishes the exact validation checklist before stable release.

Changes:
- manifest version set to `10.0.0-rc.1`;
- release checklist added for v9.7.6 -> v10 migration rehearsal;
- EC01-EC10 smoke matrix documented for state/history, Enabled, Blocked, Stay, Activate, multi-trigger, external helper, override/interlock, legacy mirror, and restart behavior;
- validation gates documented for Ruff, pytest, HACS metadata, HACS marketplace validation, and Hassfest;
- known limitations documented for Home Assistant 2026.9 validation, guide-only Repairs, transitional legacy mirror behavior, and historical v9 test files.

Known limitations:
- GitHub Actions still install Home Assistant 2025.1.4 for this branch, so real Config Subentry validation must happen in a Home Assistant 2026.9 environment before stable release;
- migration Repairs remain guide-only and do not delete Helpers or rewrite YAML;
- the release checklist is the authoritative smoke script for the RC window.
