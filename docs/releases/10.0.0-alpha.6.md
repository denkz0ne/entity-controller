# Entity Controller 10.0.0-alpha.6

Date: 2026-09-30

Sixth v10 architecture milestone. This prerelease is the first controlled migration-test build for legacy v9 YAML.

Changes:
- legacy YAML parser and migration report model;
- one v9 controller maps to one v10 controller subentry data payload;
- idempotent import when existing subentry ids are supplied;
- known v9 fields mapped for triggers, controls, state entities, overrides, interlocks, delay, duration sensors, block timeout, backoff, behaviours, and night mode;
- unknown legacy fields become explicit migration warnings;
- external Helpers remain references only and are not converted into EC-owned entities;
- temporary legacy entity mirror for `entity_controller.<object_id>` state compatibility;
- migration docs.

Limitations:
- importer is not yet wired into Home Assistant startup/Repairs;
- no production migration automation yet;
- real HA 2026.9 validation is still required.
