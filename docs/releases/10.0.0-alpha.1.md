# Entity Controller 10.0.0-alpha.1

Date: 2026-09-30

First v10 architecture milestone. This prerelease introduces the typed Config Entry runtime skeleton and begins the migration away from the v9 monolithic/YAML-first implementation.

Changes:
- adds typed controller/runtime models and explicit v10 FSM state enums;
- stores the root runtime manager in `ConfigEntry.runtime_data`;
- removes `transitions` from the v10 dependency model;
- updates integration metadata to the `denkz0ne/entity-controller` fork;
- declares the integration as a Home Assistant `helper` with `calculated` IoT class;
- documents the v10 development branch and Home Assistant 2026.9+ target.

Limitations:
- no Config Flow/Subentry UI yet;
- no migration from v9 YAML yet;
- no native controller entities yet;
- intended for architecture/testing only, not production migration.
